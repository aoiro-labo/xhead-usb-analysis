# captures/

実機から取得した生データ置き場（USBキャプチャ、RTL-SDR IQデータ等）。

- 大容量・バイナリのため、既定では `.gitignore` によりリポジトリにコミットされない。
- 解析上重要で他者と共有したいサンプルは、間引く/トリミングするなどして
  サイズを抑えたうえで個別に `.gitignore` の除外ルールを追加すること。

## 想定サブディレクトリ

- `usb/`   … USBPcap (`.pcapng`) キャプチャ
- `rtlsdr/` … RTL-SDR IQキャプチャ (`.cu8` / `.wav` 等) とその解析結果
